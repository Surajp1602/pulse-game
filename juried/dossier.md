# Dossier: PULSE

**What it is:** an original real-time party game for 2–8 players, each on their own phone, joined by a
four-letter room code. No install, no account.

**Audience:** friends in one room or on a call; mixed ages; often one person hosts on a laptop or TV.

**The game (approved design):** 12 micro-challenges in three families (Trivia: Higher/Lower, Which Came
First, Closest Call; Reaction: Colour Clash, Needle, Dot Count, Quick Draw, Memory Flash; Word: Unscramble,
Odd One Out, Missing Letter, Category Snap). Everyone plays the same challenge simultaneously for 5–10 s.
Scoring: 100 for correct + up to 100 for speed (precision games 0–200), streak ×1.25 / ×1.5, +25 for the
fastest correct, every 5th round is a "Double Pulse" (×2) with a ×1.25 "Surge" for the bottom half.
Standard game = 3 sets × 5 rounds ≈ 8 min.

**Bots:** 8 named personas (Byte the Ace, Juno Steady, Zip Speedster, Mochi Careful, Rook Trivia Buff,
Pixel Reflex, Wren Wordsmith, Dash Streaky), Easy/Normal/Hard/Mixed, clearly tagged BOT, same rules.

**Proof / content rules:** every trivia fact in the game is a real, rounded, well-established value; no
invented testimonials or stats anywhere. The screens shown are rendered from mock game state (player
names Priya, Tomás, Mei are sample players).

**Brand:** new. Name PULSE; identity defined in brief.md (warm black, vermilion signal, Bricolage
Grotesque + Manrope, the Pulse Line).
